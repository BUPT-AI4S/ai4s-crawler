# 精筛与标签规则

| 判定 | 依据 |
|---|---|
| 纳入 | 有明确的科学或工程研究任务，AI 实质参与其中，摘要或原文支持两者的关系。方法、数据资源与综述也可纳入，须有对相关研究任务的直接贡献。 |
| 排除 | 主要是通用模型、推理效率、软件工具或常规业务应用，现有证据未显示实质科学研究任务。只提领域愿景或以领域数据演示通用性能，不能单独支撑纳入。 |
| 待定 | 现有证据不足以辨别 AI 的角色、科学贡献或两者关系。记录待查证据。 |

摘要足以判断时，证据位置写「输入摘要」。需要查证时优先使用正式论文页或公开原文，并记录章节或图表位置。代码命中词、会议分轨和既有标签只作线索。发现候选内元数据冲突或版本重复时记录依据，避免把同一篇重复计数。

## 文献类型

- 只纳入原创研究正文（包括正式会议研究论文）和有实质学术内容的综述。方法论文、数据论文等按其是否构成原创研究判断。通过类型核验后，继续按 AI4S 相关性和证据规则精筛。
- 评论、社论、读者来信、新闻、广告、宣传稿、更正、撤稿公告和会议摘要条目按类型排除。以出版方文献类型、栏目及正文核实。若类型不清且证据不足，记为「待定」。对已有候选保留排除记录，并在理由中注明类型。

## 官网总量与漏采核验

- 按 `venue` 和 `year`，用同一快照的 `snapshot.json` 中 `papers` 或 `papers.json` 统计全量采集数。期刊查出版社正式卷期目录，会议查当届正式论文集和纳入范围内的分轨。记录官方 URL、统计范围和日期。候选数量用于评估精筛工作量，不能用于与官网总量比较。
- 先对齐统计口径，包括正式出版年与在线优先日期、正会与 Workshop、增刊、文章类型、重复或撤回记录，以及官网截至日期。统计口径一致后比较总数；若数量不同或怀疑漏采，以 DOI、官方论文 ID 或题名和作者逐条核对有疑问的部分。总数一致仍可能有重复或漏项互相抵消。官网没有可核验的目录或总数时，写明「无法核实」及原因。
- 对照官网确认具体论文确实漏采且属于本批范围后，可从官方论文页补录题名、作者、年份、DOI 或稳定官方 ID、论文链接和可取得的摘要。先与已有全量记录和候选去重，再按同一初筛和精筛规则处理。记录官网证据和补录原因。缺口较大时建议按官网目录批量补采并重跑初筛，暂无法核实的差额留在交付说明中。
- 精筛前，将本人负责来源的全量论文与候选按 DOI 或稳定官方 ID 对照。官网总数对齐后，仍需检查已爬到但未命中关键词的论文，优先检查相关卷期、分轨和主题，并结合标题或作者关键词定位可疑记录。主要用正式摘要判断是否漏筛。缺摘要优先从出版社或正式论文集补齐原摘要，查不到时用可核实的正文补证。经证据确认符合纳入范围和 AI4S 条件的漏筛论文可补入候选，不要求再次命中原关键词。记录检查范围、结果和仍未覆盖的部分。

## 摘要覆盖与初筛质量

- 按 `venue` 和 `year` 分别看全量采集记录和初筛候选。两者各记总数、缺摘要数和比例。空值、空白和明确的占位文本均算缺摘要。全量优先使用同一快照的 `snapshot.json`，其中缺摘要数为 `papers - with_abstract`。若统计口径不明，可用对应的 `papers.json` 核实。只有候选文件时，只报告候选覆盖，全量覆盖标为未知。
- 判断缺失是否集中在某个年份、分轨、卷期或论文类型，及这些记录是否可能包含 AI4S 相关工作。全量缺失会使摘要关键词和分类规则漏掉部分论文，即使候选的摘要很齐也可能漏筛。候选缺摘要则影响逐篇纳入判断和打标。缺失比例结合篇数、分布和可补证情况由负责人判断，不设统一通过线。
- 缺口可能影响初筛时，可挑少量有代表性的缺摘要记录（包括未命中的记录），从正式论文页或公开原文查证，说明样本能支持什么判断。审核人决定正常精筛、先精筛证据充分的部分，或暂缓并建议补摘要后重跑初筛。抽查发现的疑似漏筛项记入交付说明。
- 单篇缺摘要时，优先找正式论文页、公开原文中的方法或实验补证。证据仍不足就记「待定」，写明缺什么。来源的摘要覆盖风险单独记录。

## 标签规范

每次精筛前从团队仓库拉取最新 [共享标签词表](tag-vocabulary.json)。按实际贡献用词表中的规范标签，中文和英文成对交付。词表初始条目来自 `ai4s_taxonomy.json` 的 12 个类别和 30 个方法概念。分类关键词和正则用于初筛匹配，词表中的标签仍需论文证据支持。按需使用 `domain`（领域）、`task`（任务）、`contribution`（贡献）、`training_stage`（训练阶段）、`method`（方法）或 `evaluation`（评测）。某一维度没有明确证据就省略。

- 用短语表示一个概念。把「蛋白质序列掩码预训练」拆成任务「蛋白质序列建模」、阶段「预训练」、方法「掩码建模」。实际输出只保留论文证实且有检索价值的项。模型名称、具体数据集和实验细节可写在证据里。
- 先按维度、中文名、英文名和别名查重。语义相同就复用规范名。确需新增时，在共享词表追加一条，填 `axis`、`label`（中文）、`label_en`（英文）和 `definition`（适用范围）。常见同义写法可放入 `aliases`。提交前再同步一次，有同义条目时合并并改用已有规范名。将词表和使用新标签的精筛结果一起提交，避免新标签只出现在个人文件。
- 区分提出、改造与使用。仅使用现成模型推理时不标预训练或后训练。构建评测数据和使用已有基准分别记录。标自主实验室时核实是否有实验执行和反馈闭环。
